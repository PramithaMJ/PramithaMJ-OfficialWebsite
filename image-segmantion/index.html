How Otsu's Algorithm Works

  1. Load grayscale image
  2. Add Gaussian noise to the image (optional)
  3. Calculate the image histogram
  4. For each possible threshold (0-255):
    • Separate pixels into two classes (background and foreground)
    • Calculate the class probabilities and class means
    • Calculate the between-class variance
  5. Select the threshold that maximizes between-class variance
  6. Apply the threshold to create binary segmentation

How Region Growing Works

  1. Load grayscale image
  2. Select seed points (manually or automatically)
  3. Calculate mean intensity of seed points
  4. Use breadth-first search to explore neighboring pixels
  5. Add pixels to the region if their intensity is within the threshold of the region mean
  6. Continue until no more pixels meet the criteria
