Image Segmentation Tools

Computer Vision Algorithms Implementation

This project demonstrates two fundamental image segmentation algorithms implemented as part of my Computer Vision coursework (EC-7212).

1. Otsu's Thresholding Algorithm

Automatic image thresholding method that calculates the optimal threshold by maximizing between-class variance. This implementation includes Gaussian noise simulation to demonstrate robustness.

OpenCV NumPy Matplotlib

2. Region Growing Segmentation

Pixel-based segmentation method that grows regions from seed points by including neighboring pixels that meet similarity criteria. Interactive seed point selection for dynamic segmentation.

Python Computer Vision Image Processing
